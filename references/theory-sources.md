# 理论来源与覆盖

理论起点是《金融市场技术分析》与《日本蜡烛图技术》的讲课笔记，不是两本完整教材。开发时核对过36页截图，公开版只提供自行整理的规则、工程实现和定位索引，不包含第三方讲义、截图及含原图的融合PDF。见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

用户可自行提供合法取得的原资料，私下放入 assets/source-notes；缺少资料仍可计算并绘制合成示意，但不能声称已完成原图核对。A1—A15、B1—B21、G01—G46仅是历史定位编号。

- [原页覆盖矩阵](原页覆盖矩阵.csv)、[图表覆盖矩阵](图表覆盖矩阵.csv)、[名词覆盖矩阵](名词覆盖矩阵.csv)：原页与融合版的映射。
- [41条量化规格](rules.v0.4.json)：Q01-Q41定义及引用，是规格存档；结合[实现清单](implementation-coverage.csv)判断算法是否已做。JSON内旧状态是当时快照，不能作为新运行结果。

读图时解释趋势背景、位置、比例关系、前后确认和失效条件，不只复述图形名称。引用原图须指明来源页；重新绘制的示意须标“合成理论示意”，不假冒原书图。每次实际行情图必须来自当轮数据。

BBI连续背景、日周回踩加分、多模型冲突解释、每轮图表对照均是用户后续要求，不能归功于原讲义。规则优先级：本轮用户要求 → SKILL.md和decision-rules中的当前口径 → 历史规格与讲义。历史规格中的候选买入术语不能恢复成独立BBI信号。

Q11-Q31已接入因果自动扫描，Q32-Q34已接入融合候选、配置式研究模拟和时间切分事件研究。原页没有精确数值定义的旗形、三角旗、楔形、三角形、圆弧、喇叭、菱形及近似蜡烛子型统一标为HEURISTIC；这表示程序能够按公开工程定义扫描，不表示算法已经复原作者未写出的边界。所有模型仍未完成盈利优势的独立样本外验证。
