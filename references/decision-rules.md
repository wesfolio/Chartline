# v2.2顺序覆盖

以下BBI规则只用于讲义方向冻结后的最后阶段。前面的走势判断禁止使用BBI位置、斜率、连续根数或触线作为方向证据；原有“BBI模型方向”字段只解释该指标状态，不并入讲义结论或投票。先按27个讲义框架分析，再讨论是否买入和价格节奏。

# BBI与模型解释

BBI=(SMA3+SMA6+SMA12+SMA24)/4；日周收盘各自计算。配置在scripts/inputs/bbi-evidence-config.json。有效先行连续根数不包含当前bar，等于／低于BBI、数据缺口或价格不可用会中断。真实触线参考是上一完成bar的BBI，不使用事后变化的本根BBI回填盘前条件。0.2×ATR带只显示接近程度，不增加触线支持。

背景不足、未触线、触线后收盘低于参考，均不产生BBI支持。严格高于用于连续背景；收盘恰好等于上一BBI仍满足本根守线约定。默认5日/3周及守线约定都须作为研究参数披露。sufficient_to_buy=false、buy_action=null，无数值打分权重。各周期独立；股票基本面未知不能被自动升级为已验证。

模型阅读顺序：

- 结构：最近两个已确认高点与低点，上下方向一致才有UP/DOWN；确认需后续两根完成K线，记录pivot_date和known_date。MIXED不是箱体识别。即使确认结构未更新，也须检查当前价格是否已越过旧锚点。
- BBI：价格在线上且线抬高，支持均线趋势；价格线下且下行支持弱势。位置与斜率混合时保留分歧。触线支持与趋势方向是不同字段。
- MACD：SMA种子EMA12/26，DEA为DIF的EMA9，柱体=DIF-DEA（不乘2）。零轴、信号线关系、交叉分别解释；不要把全部组合强迫归成涨或跌。
- RSI14：Wilder平滑；高低极值不自动代表价格马上反向。背离需对应已确认价格枢轴，并披露锚点年龄；当前实现3点RSI差和0.1×前ATR价格容差为研究设定。
- 相对量：本根量除之前20根均量。盘中累计量不得作为完整全天量或同分钟历史量比。
- 吞没候选：结合前趋势、实体覆盖及容差，仅为候选，后续突破确认、失效及到期见patterns.json中的Q13生命周期。

所有状态、价位和推理须能追溯到本次features与原数据。相关均线、MACD以及同品种主连和加权不作独立投票；没有经过样本外校准不报上涨概率。交易时点、手续费、涨跌停、最小报价单位、复权价格映射、公司行为和可成交性均不能由K线形状代替核验。

脚本model_rows给出的是模型层通用解释，代理须结合当轮实际状态写综合判断，特别是短期和较长期模型冲突时。只有当前请求明确要求基本面时才把有证据的基本面判断合入，不把先前某次“忽略基本面”设为所有请求的永久规则。
