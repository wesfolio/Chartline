# v2.2报告顺序覆盖

BBI及其图表、规则审阅、交易计划统一置于报告最后。先保存不含BBI的book-judgment.json，报告主结论只能来自它。正文和图表不得提前嵌入BBI辅助线；前面的模型比较与置信强弱不受个人经验影响。render_report必须传--book-judgment；旧叙述文件不兼容正式模式，需按新契约完成两个阶段，不能直接复制旧判断冒充独立分析。

# 图表、文字与报告

每次买入/不买入结论至少展示日周BBI、决定结论的趋势结构和主要反对模型。自动报告展示所有当前实现模型；不适用的形态页必须标出“不适用”，不能把理论示意当作实际识别结果。

理论图由确定性几何规则绘制，明确标为合成示意。实际图来自与指标完全相同的JSON，币种、复权口径、日期与成交量单位必须可识别。对照说明相似部分、不满足部分和对结论的作用。BBI的0.2ATR观察带不是触线证据；前一期BBI是静态参考，并非下一日可成交的限价。

报告正文、英文、数字、页码及图表标注均用宋体，标题用黑体；输出文字只使用宋体或黑体。附目录、页码、名词解释和模型页索引。render_report输出PDF和每个模型的可缩放SVG，目录及模型索引采用多遍排版自动计算页码并建立书签。仍需检查段落和图表是否溢出。

以下是叙述部分的示例，不能单独用于正式报告。正式报告还必须加入[结论契约](decision-contract.md)规定的conclusion对象；仅检验版式使用--draft。

```json
{
  "headline": "填写本轮短期倾向及证据强弱",
    "summary": "解释日周趋势、形态状态、动量分歧与相关市场如何共同改变判断；写出限制。",
  "scenarios": [
    {"condition": "来自实际数据的确认条件", "interpretation": "满足后如何调整方向判断", "levels": "价位、来源与口径"}
  ],
  "model_notes": {
    "equity_daily:Q36": "理论回调条件与实际图的相同、不同之处，以及为何仅算辅助证据。"
  }
}
```

写报告前核验目标日和观察时间、最新完整交易日、所有缺项，以及每条相关序列的代码、供应商、构造方法和实际暴露。价格条件必须引用当轮计算结果，不沿用旧报告价格。短期预测写条件情景；不得编造开盘价、精确盘中路径或未经校准的胜率。

报告生成后用PDF工具渲染所有页面，检查目录页码、图表刻度、正文截断、字体、页间溢出和日期。脚本成功不代替视觉检查。默认报告中的所有模型说明会占较多页；按用户需要裁剪时需同步目录与索引。

全部相关序列的相关性在analysis.json保留。PDF列出本轮实际配置序列的窗口结果。若不同供应商、指数、连续合约或固定合约结果不同，必须在综合判断和对应模型注释中说明，不能隐藏交叉核验数据。

可用featured_pattern_ids显式选择本轮latest_patterns中的关键事件，包括OBSERVED十字与纺锤；pattern_notes按事件ID填写本轮解释。sources列出实际行情与日历核验来源。单根与多根蜡烛的实际对照窗口缩至近期，避免关键形态在长图中不可辨认。
